# 💡 Gerador de Citações em Python

Aplicação em Python desenvolvida para demonstrar organização de código modular, boas práticas e manipulação de estruturas de dados.

##  Funcionalidades
- Geração de citações aleatórias.
- Filtragem de citações por categorias (`tecnologia`, `motivacao`, `filosofia`).
- Interface de linha de comando (CLI) interativa.
- Tratamento de exceções e entradas inválidas.

##  Tecnologias Utilizadas
- **Python 3.x**
